# Project Data

Currently, the project uses a dataset of personal vehicles and their owners from the [Open Data Portal of Ukraine](https://data.gov.ua/dataset/06779371-308f-42d7-895e-5a39833375f0). The dataset contains information about various types of vehicles owned by individuals, including details such as vehicle type, ownership region, and registration date.

The raw files should be put into `data/raw/` directory manually, while any processed files generated during the analysis should be stored in `data/processed/`. Both directories are not tracked in git to avoid cluttering the repository with large data files.
